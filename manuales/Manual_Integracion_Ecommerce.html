Manual de Integración Webhooks: E-Commerce y Redes Sociales

Este documento explica cómo configurar sus tiendas online (WooCommerce / Shopify) y redes sociales para que envíen las órdenes de venta y los mensajes directamente a BetoGraf POS.

1. Requisitos Previos

  1. BetoGraf POS (Versión 2.3.9.10 rev.1.0 o superior) instalado y en funcionamiento.
  2. Contar con un túnel inverso o IP Pública estática para que la red externa pueda comunicarse con el POS.
Nota: Si no cuenta con IP pública, recomendamos utilizar servicios como Ngrok o Cloudflare Tunnels apuntando al puerto local 8000.

2. Integración con WooCommerce (WordPress)

  1. Ingrese al administrador de WordPress (/wp-admin).
  2. Diríjase a WooCommerce > Ajustes > Avanzado > Webhooks.
  3. Haga clic en Añadir Webhook.
  4. Configure: Tema: Pedido creado | URL de entrega: [SU_URL_BASE]/pos/webhooks/woocommerce/.
  5. Guarde y realice un pedido de prueba.

3. Integración con Shopify

  1. Ingrese a Configuración > Notificaciones > Webhooks en Shopify.
  2. Configure el evento a Creación de pedido (JSON).
  3. URL: [SU_URL_BASE]/pos/webhooks/shopify/
  4. Guarde y envíe una notificación de prueba.

4. Redes Sociales (Omnicanal)

Configure Facebook Messenger, Instagram o WhatsApp en Meta for Developers apuntando a [SU_URL_BASE]/pos/webhooks/rrss/ con el token provisto por soporte.
