Manual de Configuración de Terminales POS y Pasarelas

Este documento explica cómo configurar sus equipos físicos de venta (Transbank, MercadoPago Point, SumUp) y pasarelas de pago (Flow) dentro del sistema BetoGraf POS.

1. MercadoPago Point

  1. Ingrese a MercadoPago Developers y copie el Access Token.
  2. En BetoGraf POS, ingrese a Panel Admin > Configuración > Pagos.
  3. Pegue el Access Token y haga clic en "Escanear" para encontrar su terminal.

2. SumUp

  1. Obtenga su token OAuth desde SumUp Developers.
  2. Ingrese el Token y el Merchant Code en la Configuración de Pagos.

3. Transbank

Para terminales locales, utilice el puerto COM de su equipo Windows. Para Webpay REST, ingrese el Commerce Code y la API Key otorgada por Transbank en el apartado de Pagos.

4. Flow (Pasarela de Pagos / Códigos QR)

  1. Desde Flow.cl > Integración API, copie su API Key y Secret Key.
  2. Péguelas en la opción Flow dentro de Configuración > Pagos en BetoGraf POS.
  3. Guarde y comience a generar solicitudes de cobro automáticas.
